# 质量门禁命令（Quality Gate Command）

按需对指定文件或项目范围运行 AAN 质量流水线。

## 用法

`/quality-gate [path|.] [--fix] [--strict]`

- 默认目标：当前目录（`.`）
- `--fix`：在已配置的工具上允许自动格式化 / 自动修复
- `--strict`：在受支持的工具上将警告升级为失败

## 流水线

1. 对目标检测语言与工具链。
2. 运行格式化检查（formatter）。
3. 在可用时运行 lint / 类型检查。
4. 产出一份简明的修复建议清单。

## 说明

此命令与 hook 行为保持一致，但由使用者显式调用。

## 参数

$ARGUMENTS：
- `[path|.]` 可选的目标路径
- `--fix` 可选
- `--strict` 可选
