# Web 设计品质标准

## 反模板政策

不要交付长得像通用模板的 UI。前端产出应当看起来是有意图、有态度、与产品本身匹配的。

### 禁用模式

* 默认的 card grid，间距均等、缺少层级
* 标准模板感的 hero 区块：居中标题 + 渐变色块 + 通用 CTA
* 原封不动的第三方库默认样式，冒充成品设计
* 毫无层次、深度或动效的扁平布局
* 所有组件的圆角、间距与阴影完全统一
* 灰底白字加一个装饰强调色的"安全"配色
* 套路化仪表盘：侧边栏 + 卡片 + 图表 + 无观点
* 未经审慎选择就使用默认字体栈

### 必备品质

每个有意义的前端界面应至少体现以下四项：

1. 通过尺度对比建立清晰的视觉层级
2. 间距节奏有意图，而不是处处统一内边距
3. 通过重叠、阴影、表面或动效表现深度或层次
4. 具有字符气质与真实搭配策略的排版
5. 颜色承担语义，而非仅作装饰
6. hover、focus、active 状态是被精心设计过的
7. 在合适的地方采用破格排版或 bento 布局
8. 与视觉方向相称的纹理、颗粒或氛围
9. 用于澄清流程而非干扰的动效
10. 数据可视化视为设计系统的一部分，而非事后补充

## 写前端代码之前

1. 选定一个具体的风格方向，避免"简洁极简"这类模糊默认。
2. 有意图地定义配色。
3. 主动选择字体。
4. 搜集至少一小组真实参考案例。
5. 合理使用 AAN 的设计/前端技能。

## 值得参考的风格方向

* 编辑/杂志风（Editorial / magazine）
* 新粗野主义（Neo-brutalism）
* 具备真实深度的玻璃拟态（Glassmorphism with real depth）
* 对比有度的黑金/白金奢华风
* Bento 布局
* 滚动叙事（Scrollytelling）
* 3D 整合
* 瑞士风/国际主义（Swiss / International）
* 复古未来主义（Retro-futurism）

不要默认切到 dark mode。选择产品真正需要的视觉方向。

## 组件检查清单

* [ ] 它是否不再像默认的 Tailwind 或 shadcn 模板？
* [ ] 它是否拥有刻意设计的 hover/focus/active 状态？
* [ ] 它是否依靠层级而非统一强调？
* [ ] 它放进真实产品截图里是否可信？
* [ ] 如果同时支持深浅两种主题，两种是否都感觉有设计意图？
